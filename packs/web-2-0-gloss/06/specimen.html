Version 2 of the notes API is open to everyone

Posted on 12 October by Ines Varga, filed under release api

See the reference

What changes today

After six weeks behind a sign-up list, version 2 is switched on for every key. Nothing you have written stops working: version 1 keeps answering for a year, at its old address.

Answers in JSON

Every method now answers in JSON unless you ask otherwise. Add format=xml to a call and you get the reply you are used to. The names of the fields are the same in both.

Three things to check in your program

  • Calls go to /v2/ instead of /v1/.
  • Lists come twenty to a page, not fifty.
  • A missing note answers 404, no longer an empty list.

The full list of methods, with their limits, is in the reference.

The same call, old and new

before  GET /v1/notes.xml?book=harbour
now     GET /v2/notes?book=harbour
