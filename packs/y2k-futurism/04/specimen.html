Drawing your first skin

By the skins desk, 31 May

A skin is a folder of small pictures and one text file. An evening is enough to make the player your own.

What you need

Any paint program that saves bitmaps will do. Work at actual size: the main window is only 275 pixels wide, so every pixel shows.

  • The skin builder kit
  • A paint program
  • A zip tool

Drawing the parts

Start with the main window and leave the buttons for last. Draw each button twice, up and pressed, and keep both on the same sheet.

Testing it

Zip the folder, rename it and start the player with chronoskin --skin test.zip. Broken parts show in plain grey.
