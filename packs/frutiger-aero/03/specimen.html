Move to a new computer

Your library lives on our servers as well as on your devices, so a new computer only has to sign in and fetch it. Allow an evening for the first pass.

Before you start

  • Let the old computer finish syncing: the status window should say All in step.
  • Have your sign-in name and password to hand.

On the new computer

  1. Download the installer and run it.
  2. Sign in, then type the code it shows, for example 7KQ4-M2XD.
  3. Choose which folders this machine should hold.

If the old computer is gone

Remove it from your device list so that it no longer counts towards your plan. Nothing in your library is deleted.

Quick answers

Does removing a device delete my library?

No. Only the link between this device and your plan is removed.

Can I add it again later?

Yes. Add it from the Setup page whenever you like.
