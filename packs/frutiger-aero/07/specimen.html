Your first gadget

A gadget is a folder with two files in it: a page that draws the gadget and a settings file that tells the desktop its name and size. This guide builds a small clock and puts it on the desktop. Nothing has to be installed except the kit.

Make the folder

Create a folder called hello.gadget anywhere you like. The ending matters: the desktop treats every folder that ends in .gadget as one gadget.

  • gadget.page holds what the gadget shows.
  • gadget.settings holds its name, its size and what it may read.
  • Anything else in the folder, such as sounds, is packed along with it.

Say hello

Open gadget.page in a text editor and type the lines below. The clock object calls your function once a minute, so the gadget never has to ask for the time itself.

gadget.title = "Hello";
gadget.size(130, 130);

clock.every("minute", function () {
  face.text = clock.time("HH:mm");
});

gadget.show();

Try it

Double click the folder. The preview tool opens the gadget on a sheet of glass and reloads it every time you save. When the clock looks right, read on in Settings and storage.

Reading an entry ?Entries are listed in alphabetical order.

Each object has a page of its own that lists its members in the order you are likely to need them. Since is the first kit version that had the object; a gadget that names a newer object will not start on an older desktop, so set needs in the settings file to match.

Common questions

Which file draws the gadget?

The page file named in the settings file.

Can a gadget run in the background?

No. It runs only while it is on the desktop.
