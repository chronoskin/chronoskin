chronoskin prints a timetable from a text file.

You keep one plain file of times and what happens at them. It gives you back a week, a month or a single day, as text you can read, print or pipe.

chronoskin [-w | -m | -d date] [-f format] [-o file] timetable.txt
chronoskin -c timetable.txt

Chapter 3. Options

Fourteen flags, each one letter. All of them can be left out.

This chapter as text

Reading

How options are read

Options come before the name of the timetable file and are read from left to right. When two of them disagree, the later one wins, so a shell alias can set your habits and the command line can still overrule them.

Choosing the span

With no option at all the program prints the current week, Monday first. Three flags choose something else, and only one of them may be given:

  • -w prints a week, which is the default.
  • -m prints the whole month, one line a day.
  • -d 2017-03-14 prints that one day in full.

Dates

A date is always year, month, day with hyphens. Nothing else is accepted, and a date that does not exist ends the run with status 2.

Upgrading

Releases within a series read the same files and take the same options. Between series, read the first entry of the new one before you replace the binary.

To see what you have, run chronoskin -V.

From 1.x to 2.x

Weeks start on Monday unless the file says otherwise. Add week sunday as its first line to keep the old behaviour.

Checking a file

Every file is listed in SHA256, which is signed. Fetch both, then:

sha256sum -c SHA256
signify -V -p chronoskin.pub -m SHA256

Mirrors. The two mirrors copy this directory once a night. A release less than a day old may not be on them yet.

Building

There is no configure step. Unpack, build, and copy one file to where you keep programs:

tar xzf chronoskin-2.4.1.tar.gz
cd chronoskin-2.4.1
make && make test
cp chronoskin ~/bin/

What it needs

A C compiler from this century and make. The tests also want diff.

It did not build

make: cc: not found

No compiler is installed. Install one, or set CC to the one you have.

One test fails on dates

Your clock is in a zone that changes this week. Run the tests again with TZ=UTC.

Permission denied on copy

Copy the binary to a directory of your own; nothing needs root.

Before you write

  1. Run chronoskin -c on your file.
  2. Check the changelog.
  3. Find the smallest file that shows it.
