How the directory works

Every site here was visited by an editor.

The directory lists more than 40,000 sites in ten subjects. Every listing is visited by a person before it is added, and checked again twice a year. Start from a subject on the front page, or type a few words into the search band.

Building your first page

A page is a plain text file. Save it with the name index.html and send it to your provider's server. The sites in Web Authoring show how, step by step.

  • Keep each page under 40K so it loads over a modem.
  • Give every page a title.
  • Test in more than one browser.

Reading the links

Links are underlined everywhere on chronoskin, and their colour tells you where you have been.

A link you have not followed - a link you have visited - a link under the pointer - a link as you click it - a sponsor's link - a bold link
