Ask a Question

Reports print one line too low on continuous paper

Applies to Ledger 3.0 and 3.1 with a dot matrix printer.

Ledger measures a page as 66 lines. Some printers count 72 when the paper is fed by tractor, so each page starts a little lower than the last. The cure is to tell Ledger the true length in the file LEDGER.INI.

What to do

  1. Close Ledger and open LEDGER.INI in Notepad.
  2. Find the line that begins PageLines= and change the number to 72.
  3. Save the file, start Ledger and print one test page.

If that does not help

Check that the printer's own form length switch agrees with the paper. These pages may also be useful:

An answer you have not read, one you have read, one under the pointer, one as you click it, a bold link and a small link.

Still stuck?

Send the file to us with a note of your printer's make and we will set it for you. Report a problem
