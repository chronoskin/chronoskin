Before the release

Work through this list for every release of the platform. Each step has one owner; if you cannot finish yours, say so on this page before the freeze, not after.

  • Freeze the branch with make freeze VERSION=2.4.
  • Run the smoke tests on the staging machines.
  • Write the release notes from the change log.

After the release

Watch the error log for an hour, then close the release page and open the next one. See the rollback plan if anything goes wrong.
