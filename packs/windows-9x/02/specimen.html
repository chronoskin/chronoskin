Q1042: Mail merge prints one blank envelope after every letter

Applies to Writer 3.0 and later.

When a merge ends with a page break, the printer is sent one more empty page for every record. On most printers that page is fed from the envelope tray.

To stop it

  1. Open the letter and go to the last line.
  2. Choose Reveal Marks from the View menu and delete the final break.
  3. Save the letter and run the merge again.

If you start merges from a batch file, add the switch /nobreak instead, as in writer /merge list.dat /nobreak.
