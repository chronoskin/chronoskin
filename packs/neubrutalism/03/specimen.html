Four short pages. Read the second one and you can start.

Try it on a block

Copying a block

A block is one file of markup and the classes it needs. Nothing is installed, so nothing can go out of date behind your back.

Three steps

Pick a block, press copy, paste it where the screen needs it. Set data-density on the wrapper if the table should be tighter.

  • Keep the class names as they are
  • Change the words, not the spacing
  • Put one primary action on a screen

When a block does not fit

Take the nearest one and remove parts. Removing is always safe; adding a new kind of box rarely is.
