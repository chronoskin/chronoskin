How the kit is organised

Three modules, each usable alone: one reads, one stores, one draws.

Reading levels

A reader wraps one gauge and reports a level in millimetres. Set the interval with reader.every and the kit handles sleep and wake-up. The gauge table lists supported hardware.

  • Readings carry a time and a quality flag.
  • A missed reading is recorded, never guessed.
  • Two readers can share one clock.

Install

Add the modules you need and build.

chronoskin add reader store
chronoskin build --target wall
Before you deploy Wall displays need release 3.0 or later of the draw module.
Build stopped No gauge is configured for the target. Add a reader and build again.
