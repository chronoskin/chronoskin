Quick start

From an empty folder to a first message in about ten minutes.

Open the channels

Send a first message

A message goes to a channel, and the channel decides how it reaches the reader.

Create a key

Every call is signed with a project key. Make one for a channel, then keep it in chronoskin.key next to your code. The channel settings show which key is in use.

  • A key belongs to one project and one channel.
  • Rotate a key without stopping delivery.
  • Revoked keys fail at once, with a clear error.

Send from the command line

Install the tool and send a test message to yourself.

chronoskin login --project night-desk
chronoskin send --channel mail --to me "First light"
