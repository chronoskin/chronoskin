Snapshots of a directory, kept as plain files.

chronoskin copies a directory into a dated snapshot, shares unchanged files between snapshots and thins old ones on a schedule you write down. This is its whole manual: fourteen pages, the same text that man shows.

chronoskin

Keep dated snapshots of a directory as plain files.

Synopsis

chronoskin [-c file] [-q] verb [options] [arguments]

Description

chronoskin copies a source directory into a store. Each run of take makes one snapshot, a directory named by date and time. A file that has not changed since the last snapshot is linked, not copied, so a snapshot costs only what changed.

A snapshot is an ordinary directory. You can read it with any program, and restore is only a careful copy.

Options

-c file, --config file

Read settings from file instead of ~/.config/chronoskin.conf.

-n, --dry-run

Print what would be done and change nothing.

-q, --quiet

Print errors only.

Exit status

  • 0 when the verb finished.
  • 1 when some files could not be read; the snapshot is kept and marked partial.
  • 2 when the command line or the configuration is wrong.
