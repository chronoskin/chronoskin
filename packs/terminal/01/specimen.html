Track your hours without leaving the prompt.

chronoskin is a time tracker that lives in your shell. Start a task, stop it, and print the week as text you can read, pipe or paste into an invoice.

$ brew install chronoskin copy

Every command takes -h help and exits with 0 when it did what you asked. The full reference has all fourteen.

where it fits

01 prompt

In your shell

A status segment for bash, zsh and fish shows the running task beside your path.

02 editor

In your editor

The log is plain text, one line a task. Any editor can open, sort and repair it.

03 pipe

In a pipeline

Reports come as CSV or JSON on standard output, ready for the next program.

04 sync

In your repository

Keep the log beside the code. It merges like any other text file.

Your first tracked hour

chronoskin keeps one text file, the log, and three commands do nearly all the work: start, stop and report. Nothing runs in the background; the clock is the difference between two times in the file.

Install

Pick your system. Each line puts one binary on your path and nothing else.

  • macos
  • linux
  • windows
  • from source
$ brew install chronoskin
$ chronoskin --version
chronoskin 3.2.0

Track a task

Say what you are doing. Starting a task stops the one before it, so you never have two clocks.

  • chronoskin start "name" begins a task now.
  • chronoskin start -a 09:00 "name" begins it in the past.
  • chronoskin stop ends it and prints how long it ran.

Tags

A word after -t is a tag. A task may carry several; a report can group by any of them.
