What's new

Changes to chronoskin, newest first.

Budgets that warn you in time

A project now tells you when it is about to run out of hours, not after it has.

How the warning works

Set a budget in hours on any project. At 85% the project is marked Near budget and its owner gets one email; past 100% it is marked over budget.

Changing the threshold

The 85% mark suits most teams. To move it, open the project and set warn_at to a value between 50 and 95.

Also in this release

  • Timers survive a closed browser tab.
  • Reports can be grouped by person, then by project.
  • The weekly summary email arrives on Monday at 8, in your own time zone.
