Back office, light

Forty screens for a small back office, by Ilse Brandt.

Live preview Buy for $18
  • Description
  • Reviews 37
  • Changes
  • Support

What is in the package

Everything a small back office needs on day one, built on the framework's own grid.

The theme restyles the standard components and adds a few of its own. No markup is changed, so a page written for the plain framework takes the theme by swapping one style sheet.

Screens

  • Dashboard with summary boxes and two charts
  • Tables with sorting, filters and bulk actions
  • Forms, a calendar, an inbox and a sign-in page

Installing it

Unpack the archive and link css/theme.min.css after the framework's own file. The six colour schemes are separate files in css/schemes/.

Before you buy

Which version of the framework does it need?

Version 3. A build for version 2 is in the same archive, in its own folder.

May I use it for a client?

Yes, for one finished site per licence. A second client needs a second licence.

Do I get updates?

For as long as the theme is sold here. You are told by email and download them from Purchases.
