Access tokens

A token lets another program act as you without knowing your password.

Make one token for each program, so that you can take one away without disturbing the others. A token is shown once, when you make it; after that only its last four characters are listed.

Making a token

  • Open Profile and choose the tab Access tokens
  • Name the token after the program that will use it
  • Copy it straight away and store it somewhere safe

Using it

Send the token in the Authorization header of each request. A token that has not been used for 90 days expires on its own, and you are told two weeks before.

Other questions

I cannot sign in

Ask for a sign-in link on the first page. It arrives by email and works once, for an hour.

How do I change the owner?

The owner opens Profile, chooses another member of the team and confirms with the password.

What happens when I close the account?

Profile, sessions and tokens are removed at once. Invoices stay with the studio.
