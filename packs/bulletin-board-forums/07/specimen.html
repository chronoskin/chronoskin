About this skin

Harvest was drawn for boards that run wide: the cells are sand, the title bars brown, and links are a rust red that stays readable on both row colours. It ships with 34 buttons in English and German and a blank set.

Installing

Unpack the archive into the styles/ folder of the board and pick the skin in the administration panel.

  • Copy harvest/ with its three sub-folders, keeping the names.
  • Refresh the template cache, or the old buttons stay.
  • For 800 pixel screens choose the variant named harvest-narrow.

Changes in 1.4

The quote box no longer breaks out of narrow posts, and the private message pages use the same row colours as the rest.

See also: all board skins, Harvest buttons, blank set (visited), the matching rank images (hover), the support thread (active).
