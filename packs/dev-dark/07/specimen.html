02 / Questions

Limits, explained

What counts, what does not, and what happens at the edge of a plan.

What happens when a project reaches a limit?

Nothing stops. Reads keep working, you get a message at 80% and at 100%, and the plan is settled at the end of the month.

Is a draft a document?

A draft and its published version count as one document.

Can a dataset be moved between regions?

Yes, on Team and Scale. A move copies the dataset, then switches reads over.

How long is history kept after a downgrade?

For 30 days, so that a change of plan never deletes anything at once.

02 / Rules

What the store checks

Rules run when a document is published, never while it is typed.

Modelling an article

A type lists what a document is, not how a page shows it.

Start from the question

Write the queries the site will ask before the fields. If nothing asks for subtitle, the field is a habit and can go.

Three checks before publishing a type

  • Every reference names the type it points at.
  • A computed field such as reading_time has no form control.
  • A deprecated field stays readable until no document fills it.

Changes to a type are a migration, and each one is kept in the history.

schema / articlets
type article = {
  title: string
  author: ref<author>
  body: text // with figure
}

Validation
