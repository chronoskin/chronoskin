Which runtimes are supported?

Node.js 18, Python 3.9, Go 1.21 and Ruby 3.1, and every later version.

Is there a library for another language?

Not yet. The API is plain HTTP and JSON, so any client works.

How do I pin a version?

Pin the library as usual. Each one sends the API version it was built for.

Send an e-mail

From an API key to a message in an inbox, in about five minutes.

Try it in the console
  • Node.js
  • Python
  • Go
  • cURL
send.jsCopy
import { Chronoskin } from "chronoskin";

const mail = new Chronoskin(process.env.CHRONOSKIN_KEY);

const { id } = await mail.emails.send({
  from: "Harbour <hello@harbour.dev>",
  to: ["ada@example.org"],
  subject: "Your receipt",
  html: "<p>Thanks for your order.</p>",
});  // em_41f9c2

Before you send

You need an API key and a sender address on a domain you have verified.

Until a domain is verified you can only send to your own address. That is enough to try everything on this page.

What the call returns

  • An id you can use to look the message up later
  • The status queued, which becomes delivered or bounced
  • Nothing else: delivery itself is reported by webhook

Sending to several people

Pass up to 50 addresses in to. Each recipient gets a separate message and never sees the others.

Keys are shown once. Store the key in an environment variable, never in the repository.

403 domain_not_verified. The sender address is on a domain without valid DNS records.
